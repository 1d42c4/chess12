# Improving this course

Open an issue with a lesson or exercise ID, FEN where relevant, the disputed claim, and a concrete correction. Preserve unrelated content.

Edit data/course.json, run node tools/build.mjs, and run node tools/validate.cjs. Check the changed pages in a browser. Keep source answers and explanations consistent; changing an engine or tablebase answer requires new recorded evidence.

Use a branch and pull request. Review the complete diff before merging. Keep default-branch protections and Pages settings enabled. After merging, confirm the Pages deployment succeeds and the affected lesson works.
